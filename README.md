# Electric-Vehicle-Analysis-Dashboard

Electric Vehicle Dashboard Design and Analysis – Power BI Capstone Project
Developed an interactive Power BI dashboard analyzing 150k+ EV records to uncover market trends, manufacturer performance, and adoption patterns. Created custom KPIs, geographic and model-based insights, and enabled dynamic filtering for deep analysis. Demonstrated expertise in data cleaning, DAX, and dashboard design.


### 	Short Description / Purpose

This capstone project focused on designing a comprehensive dashboard to analyze electric vehicle (EV) population data and derive actionable insights for strategic decision-making in the clean energy and transportation sector. The dataset included over 150,000 records of EVs across multiple states, with key attributes like make, model, year, type (BEV/PHEV), electric range, and eligibility for Clean Alternative Fuel Vehicle (CAFV) programs.


### 	Tech Stack

The dashboard was built using the following tools and technologies:<br>
•	📊 Power BI Desktop – Main data visualization platform used for report creation.<br>
•	📂 Power Query – Data transformation and cleaning layer for reshaping and preparing the data.<br>
•	📂 Microsoft Excel – Data Source.<br>
•	🧠 DAX (Data Analysis Expressions) – Used for calculated measures, dynamic visuals, and conditional logic.<br>
•	📝 Data Modeling – Relationships established among tables (resorts, snow, and data_dictionary) to enable cross-filtering and aggregation.<br>
•	📁 File Format – .pbix for development and .png for dashboard previews.


### Features / Highlights

Using Power BI, the project was structured around building dynamic KPIs and visualizations to track year-on-year growth, vehicle type distribution, and manufacturer dominance (e.g., Tesla, Chevrolet). Geospatial maps were used to highlight EV distribution by state, while slicers allowed for drill-down analysis by city, utility, and fuel type.

The dashboard supports business decisions by showcasing:
Market growth trends
Top manufacturers and models
Regional saturation
Electric range averages
CAFV eligibility distributions

It also features advanced interactivity using filters, slicers, and DAX-based KPIs to enable stakeholders to explore data from different dimensions with ease.
