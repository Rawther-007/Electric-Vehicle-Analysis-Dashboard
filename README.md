# Paint Sales Analytics Dashboard

Paint Sales Performance Dashboard 
Created a comprehensive sales monitoring solution for a paint manufacturing business, tracking performance across key operational dimensions.


### 	Short Description / Purpose

Sales Analytics Dashboard | Power BI & SQL
Developed an interactive dashboard to track sales performance, regional trends, and payment method preferences for a multinational retailer.


### 	Tech Stack

The dashboard was built using the following tools and technologies:<br>
•	📊 Power BI Desktop – Main data visualization platform used for report creation.<br>
•	📂 Power Query – Data transformation and cleaning layer for reshaping and preparing the data.<br>
•	📂 Microsoft Excel – Data Source.<br>
•	🧠 DAX (Data Analysis Expressions) – Used for calculated measures, dynamic visuals, and conditional logic.<br>
•	📝 Data Modeling – Relationships established among tables (resorts, snow, and data_dictionary) to enable cross-filtering and aggregation.<br>
•	📁 File Format – .pbix for development and .png for dashboard previews.


### Features / Highlights

Key Features:

District-wise sales performance visualization
Monthly sales trend analysis
Sales type categorization (retail, wholesale, project)
Geographic sales distribution mapping
Interactive filtering for granular analysis
Technical Implementation:
Data extraction and transformation using Microsoft Excel

Dashboard development in Power BI with:
Dynamic cross-filtering
Geographic mapping
Time-series analysis
Category breakdowns

Business Applications:
Identifies high-performing districts for resource allocation
Tracks seasonal sales patterns for inventory planning
Compares different sales channels' performance
Supports data-driven territory management decisions
